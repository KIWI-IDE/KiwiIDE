# Kiwi IDE 1.0.4

## New tools

- **Editor macros:** record edits and cursor movements, save macros in your local profile, assign shortcuts, and replay them with 1–100 repetitions. Replay can be undone in one editor operation.
- **Structural search and replace:** search code patterns with named expression and argument-list placeholders across Java, JavaScript/TypeScript, Kotlin, Python, and supported C-style source files. Review before/after previews and select individual matches before applying changes.
- **GitHub Actions:** browse and filter workflow runs, inspect jobs and steps, read job logs, and explicitly re-run failed jobs after confirmation.

## Editing and dependencies

- Import Gradle project extensions, task names, configurations, and public type members for project-aware completion. Enable Gradle build-script support in the Kotlin language server.
- Keep version-catalog aliases available in complex Kotlin Gradle scripts.
- Show completion diagnostics with retry and language-server settings actions.
- Recommend dependency versions using the project's Java target, Minecraft API target, and published package metadata. Unknown compatibility remains clearly marked.
- Fix false Python indentation errors in multiline calls, tuples, joined statements, multiline headers, and inline suites. Genuine syntax errors remain visible and clear after corrections.

## Startup and appearance

- Show the IDE without a fixed splash delay; warm JDK, Gradle, and indexing services in the background.
- Synchronize the native running application/window icon with the chosen accent color, including the macOS Dock.
- Keep Kiwi Nord as the default appearance with theme and accent synchronization across auxiliary windows.

## Downloads

Windows x64 installer and portable builds, Linux x64/ARM64 AppImages, and macOS Intel/Apple Silicon DMGs are included. Choose the package for your operating system and processor.

The GitHub-based updater checks release packages for your platform. This release changes the main process and requires a full application update and restart.

## Notes

- Macro recording currently supports one cursor in the active file.
- Structural search matches code tokens and balanced delimiters; it does not perform semantic type inference. Unsaved files are skipped and stale previews are rejected.
- Private GitHub Actions data requires an account with Actions read permission; re-running jobs requires Actions write permission.
