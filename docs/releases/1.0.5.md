# Kiwi IDE 1.0.5

## Windows auto-update fix

- Fix an update handoff that closed Kiwi without running the installer. Launch the Windows update helper in an independent hidden process and confirm it is ready before closing the IDE.
- Copy update helpers into the profile before launching them, so portable extraction cleanup and replacement of the installation cannot remove the running scripts.
- Wait for the previous Kiwi process to exit before installing or replacing files, then reopen Kiwi with its saved workspace.
- Check the installed application version after setup completes. An installer that exits successfully without applying the requested version is reported as a failed update and the previous application is reopened.
- Keep update results and helper logs in the profile for diagnosis. If the helper cannot confirm its start, Kiwi stays open and reports the error.

## Updating from an affected version

If an older Windows version closes without installing an update, download and run the **1.0.5 setup installer once**. This installs the repaired updater. Portable users can replace their existing executable with the **1.0.5 portable download** while Kiwi is closed.

The full application must be updated; this fix changes the main process and cannot be applied as a renderer-only update.

## Validation

Tested with real Electron shutdown and Windows helper processes: setup installation, portable replacement, automatic relaunch, disappearing original helper files, and a setup process that exits without updating.
